# Factory Skills
---
A specialized list of (agentic skills)[https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview] that are designed to be *mostly* harness agnostic, meaning they should be able to run on most configurations. Workflow breaks up agents into tree-based teams. Each branch is built to a service layer. Each layer is proven with testing and before/after screenshots. Final review using Greptile before shipping
